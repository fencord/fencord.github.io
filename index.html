Fencord

Client mod for Fenrid. Plugins, themes, QOL stuff. Like Vencord but for Fenrid.

Install

1.
Install Violentmonkey

Get it from the Chrome Web Store.

2.
Add the script

Open Violentmonkey → click + → paste fencord.user.js → save.

3.
Open Fenrid

Go to fenrid.com and open the Fencord panel.
